# Bundled fonts (SIL Open Font License 1.1)

Digit-friendly Google Fonts, TTF via fontsource CDN, for one-click
digit BitmapList generation in the designer (Properties → Font →
Generate 0-9):

- Orbitron Bold (Orbitron-Bold.ttf)
- Oswald SemiBold (Oswald-SemiBold.ttf)
- Bebas Neue Regular (BebasNeue-Regular.ttf)
- Share Tech Mono Regular (ShareTechMono-Regular.ttf)
- Roboto Condensed Bold (RobotoCondensed-Bold.ttf)

All are SIL OFL 1.1 (https://openfontlicense.org). Custom .ttf/.otf/.woff
fonts can be imported at runtime from the same Font picker.
