# Bundled fonts (SIL Open Font License 1.1)

Digit-friendly Google Fonts, TTF via the fontsource CDN (Handjet from the
google/fonts repo, it is variable-only). All verified to contain glyphs 0-9.
Used by the designer's one-click digit/BitmapList generation, the presets and
the custom-text tool.

## Display / techy
- Orbitron Bold — `Orbitron-Bold.ttf`
- Oswald SemiBold — `Oswald-SemiBold.ttf`
- Bebas Neue Regular — `BebasNeue-Regular.ttf`
- Share Tech Mono Regular — `ShareTechMono-Regular.ttf`
- Roboto Condensed Bold — `RobotoCondensed-Bold.ttf`
- Rajdhani SemiBold — `Rajdhani-SemiBold.ttf`
- Teko SemiBold — `Teko-SemiBold.ttf`

## Segmented / matrix / pixel (clock look)
- Doto Black — `Doto-Black.ttf` (dot matrix)
- Handjet Bold — `Handjet-Bold.ttf` (element grid/shape axes; rendered with
  `wght 700, ELGR 1, ELSH 6` via `FONT_VARIATIONS` in `renderer.js`)
- Silkscreen Regular — `Silkscreen-Regular.ttf` (pixel LCD)

All SIL OFL 1.1 (https://openfontlicense.org). Custom .ttf/.otf/.woff fonts can
be imported at runtime from the Font picker.
